This means I will be able to make google searches and look syntax corrections on stackoverflow and tools like this. I shouldn't use this to debug the full code but it also ins't restricted.

STANDART LIBRARY ONLY.
This means I can't use third party libraries. I will have to use only what you get by installing go and not anything else. This secures the dependencies to minimum and ensures this code will be cross platform for a long time.
